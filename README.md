## 🛡️ ASISTEN JOE v10.5.0 -- INTERACTIVE DESIGN PREVIEW SUITE

Ekstensi pendamping Vibe Coding & Dedicated Prompt Generator di Antigravity IDE / VS Code yang mengadopsi repositori open-source tingkat tinggi teruji dari GitHub (`skills.sh`, `OpenClaw`, `Promptfoo`, & `Stanford DSPy`):

1. **Interactive Before & After Design Preview Modal Engine (v10.5.0):** Menampilkan Pop-Up Modal simulasi pratinjau visual komparasi tampilan **SEBELUM (AS-IS)** vs **SESUDAH (TO-BE)** secara interaktif sebelum Grafity/AI mengubah berkas Anda. Dilengkapi tombol `[Setujui & Salin Prompt]` & `[Edit Perintah]`.
2. **RDBMS Architecture & Migration Guard Engine (v10.4.0):** Audit otomatis skema basis data relasional (Normalisasi 3NF, Indeks B-Tree FK, Zero-Downtime Migration, SAST SQL Injection Guard).
3. **AS-IS vs. TO-BE Architectural Transformation Engine (v10.3.0):** Generator perbandingan visual side-by-side kondisi arsitektur sistem saat ini (**AS-IS**) lawan kondisi arsitektur target setelah prompt dieksekusi (**TO-BE**).
4. **Multi-Diagram Project Visualizer Engine (v10.2.0):** Menghasilkan 5 diagram visual utuh untuk proyek Anda berstandar Mermaid.js (Arsitektur C4, ERD Database, Sequence API, Git Pipeline, Gantt Roadmap).
5. **Human-Friendly Layperson Commit Engine (v10.1.0):** Mengubah pesan commit teknis yang rumit menjadi **Bahasa Awam & Bahasa Bisnis yang Sangat Mudah Dibaca** oleh Klien, Product Manager, maupun Pemilik Bisnis non-teknis.
6. **Semantic Versioning Automator Engine (v10.0.0):** Mengotomatiskan & mengoptimalkan penomoran skema Semantic Versioning (`v[Major].[Minor].[Patch]` / `x.x.0`).
7. **Anti-Layout Mutation & Asset Guard Engine (v9.9.0):** Memutus kebiasaan buruk Grafity yang sering merusak Navbar, layout CSS, atau halaman web lain saat diminta sekadar mengganti gambar/foto.
8. **Micro-Scoped Prompt Slicer Engine (v9.8.0):** Memotong instruksi bisnis/desain yang luas menjadi **Prompt Perintah Mikro Terisolasi 1-Berkas & Single-Component Lock**.
9. **Kontrak Embargo Berkas (v9.8.0):** Menyuntikkan instruksi embargo mutlak yang melarang Grafity menyentuh atau merubah berkas/fungsi di luar ruang lingkup target.
10. **Injeksi Potongan Kode Target (v9.8.0):** Otomatis membaca editor aktif dan menyertakan potongan kode asli target di dalam prompt.
11. **Mode Design & Grafity Super-Prompt Engine (v9.7.0):** Menyusun **Super-Prompt Perintah Khusus untuk Grafity** yang dipagari oleh **5 Dinding Kontrak Kepatuhan**.
12. **Multi-Agent Sub-Task Swarm Orchestrator (v9.6.4):** Sinergi 3 Sub-Agent Maya (**Software Architect $\rightarrow$ Lead Coder $\rightarrow$ SAST Security Auditor**).
13. **Inline CodeLens Provider (v9.6.3):** Menampilkan tombol `[🛡️ Asisten Joe: Susun Prompt Modul Ini]` melayang di atas fungsi/kelas editor.
14. **Hover Diagnostic Guard (v9.6.3):** Kartu peringatan kebocoran rahasia otomatis saat kursor diarahkan ke kode.
15. **Terminal Error Sensor & Repair Prompt (v9.6.2):** Menangkap pesan error terminal & menyusun Draf Prompt Perbaikan (DSPy).
16. **Pure Prompt Output Enforcer (v9.6.1):** Seluruh respons Asisten Joe SELALU diformat sebagai **Draf Prompt Presisi Terstruktur**.

## 📌 Ruang Kerja Digital (Branching Structure)

Proyek ini menggunakan 6 ruang kerja terisolasi:
1. **`main` (Sistem Utama Aktif):** Live Output.
2. **`staging` (Ruang Simulasi Akhir):** Pre-release simulation.
3. **`close-packing` (Ruang Penutupan & Audit Akhir):** Code freeze.
4. **`develop` (Ruang Integrasi Tim):** Daily integration.
5. **`feature/*` (Ruang Kerja Fitur Baru):** Isolated feature branches.
6. **`hotfix/*` (Jalur Perbaikan Darurat):** Emergency hotfix.
