## 🛡️ ASISTEN JOE v10.6.0 -- VISUAL INSPECTOR & IDE PROMPT SUITE

Ekstensi pendamping Vibe Coding & Dedicated Prompt Generator di Antigravity IDE / VS Code yang mengadopsi repositori open-source tingkat tinggi teruji dari GitHub (`skills.sh`, `OpenClaw`, `Promptfoo`, & `Stanford DSPy`):

1. **Visual Page Inspector & IDE Prompt Generator Engine (v10.6.0):** Alur kerja analisis visual halaman web pengguna:
   - 🌐 **Inspeksi Halaman Web:** Meminta tampilan halaman target (misal: `LandingPage.jsx`, `Dashboard.jsx`) dan memecahnya menjadi komponen-komponen terisolasi.
   - 🎯 **Analisis Komponen Target:** Pengguna memilih elemen/komponen mana yang ingin diubah.
   - ⚡ **Generator Super-Prompt IDE:** Otomatis menyusun Super-Prompt presisi berstandar Scope Lock & Embargo Contract untuk dikirimkan langsung ke Grafity/AI IDE.
2. **Interactive Before & After Design Preview Modal Engine (v10.5.0):** Menampilkan Pop-Up Modal simulasi pratinjau visual komparasi tampilan **SEBELUM (AS-IS)** vs **SESUDAH (TO-BE)** secara interaktif.
3. **RDBMS Architecture & Migration Guard Engine (v10.4.0):** Audit otomatis skema basis data relasional (Normalisasi 3NF, Indeks B-Tree FK, Zero-Downtime Migration, SAST SQL Injection Guard).
4. **AS-IS vs. TO-BE Architectural Transformation Engine (v10.3.0):** Generator perbandingan visual side-by-side kondisi arsitektur sistem saat ini (**AS-IS**) lawan kondisi arsitektur target setelah prompt dieksekusi (**TO-BE**).
5. **Multi-Diagram Project Visualizer Engine (v10.2.0):** Menghasilkan 5 diagram visual utuh untuk proyek Anda berstandar Mermaid.js (Arsitektur C4, ERD Database, Sequence API, Git Pipeline, Gantt Roadmap).
6. **Human-Friendly Layperson Commit Engine (v10.1.0):** Mengubah pesan commit teknis yang rumit menjadi **Bahasa Awam & Bahasa Bisnis yang Sangat Mudah Dibaca** oleh Klien, Product Manager, maupun Pemilik Bisnis non-teknis.
7. **Semantic Versioning Automator Engine (v10.0.0):** Mengotomatiskan & mengoptimalkan penomoran skema Semantic Versioning (`v[Major].[Minor].[Patch]` / `x.x.0`).
8. **Anti-Layout Mutation & Asset Guard Engine (v9.9.0):** Memutus kebiasaan buruk Grafity yang sering merusak Navbar, layout CSS, atau halaman web lain saat diminta sekadar mengganti gambar/foto.
9. **Micro-Scoped Prompt Slicer Engine (v9.8.0):** Memotong instruksi bisnis/desain yang luas menjadi **Prompt Perintah Mikro Terisolasi 1-Berkas & Single-Component Lock**.
10. **Kontrak Embargo Berkas (v9.8.0):** Menyuntikkan instruksi embargo mutlak yang melarang Grafity menyentuh atau merubah berkas/fungsi di luar ruang lingkup target.
11. **Injeksi Potongan Kode Target (v9.8.0):** Otomatis membaca editor aktif dan menyertakan potongan kode asli target di dalam prompt.
12. **Mode Design & Grafity Super-Prompt Engine (v9.7.0):** Menyusun **Super-Prompt Perintah Khusus untuk Grafity** yang dipagari oleh **5 Dinding Kontrak Kepatuhan**.

## 📌 Ruang Kerja Digital (Branching Structure)

Proyek ini menggunakan 6 ruang kerja terisolasi:
1. **`main` (Sistem Utama Aktif):** Live Output.
2. **`staging` (Ruang Simulasi Akhir):** Pre-release simulation.
3. **`close-packing` (Ruang Penutupan & Audit Akhir):** Code freeze.
4. **`develop` (Ruang Integrasi Tim):** Daily integration.
5. **`feature/*` (Ruang Kerja Fitur Baru):** Isolated feature branches.
6. **`hotfix/*` (Jalur Perbaikan Darurat):** Emergency hotfix.
